EJERCICIOS PHP - SEMANA 1

La transcripcion del video recorre estos bloques:
1) PHP base
2) Include
3) Variables de servidor
4) Objetos en PHP
5) Lectura de formularios

Cada bloque esta en su propia carpeta y tiene su propio CSS para que los ejercicios
tengan diferencias visuales en vez de ser una sola pagina enorme.

Estructura:
index.php
style.css
01_base/
02_include/
03_variables_servidor/
04_objetos/
05_formularios/

Para ejecutarlo:
1. Abrir una terminal dentro de esta carpeta.
2. Ejecutar: php -S localhost:8000
3. Abrir: http://localhost:8000/

Importante:
- El ejercicio 02 necesita asignaciones.php porque es justamente lo que muestra include.
- El ejercicio 05 se abre desde 05_formularios/index.html y envia los datos a respuesta.php.
